# 📘 Utkarsh Tuition Website

Version: v1.0.0

A **responsive tuition website** built with **HTML, CSS, and JavaScript**, following a **mobile-first design** approach.  
The project includes interactive UI elements, dynamic data handling, and a teacher dashboard with local storage support.

---

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Design Approach:** Mobile-First Responsive Design
- **Storage:** Local Storage (Browser-based)

---

## ✨ Features

- 📱 **Responsive Design** with media queries
- ☰ **Hamburger Menu** for easy navigation
- 🎞️ **Animated Carousels** for showcasing content
- 👨‍🏫 **About Me Section** introducing tutor
- 🏆 **Achievements Section** with dynamic student cards
- ✍️ **Blog Section** for updates/articles
- 🌐 **Dynamic API Fetching** (Dummy API integration)
- 🔑 **Teacher Login & Registration** system
- 📊 **Teacher Dashboard** to:
  - Add student data using a form
  - Display student cards on the home page
  - Manage cards using action buttons
- 💾 **Local Storage Support** to persist student data

---

## 🛠️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/prathamesh2503/utkarsh-tuition.git
```

2. Navigate into the project folder:
   cd project-name

3. Open index.html in your browser.

## 📖 Usage

Open the website in a browser.
Navigate using the hamburger menu.
Explore carousels, blog, and achievements.
Teachers can:
Register/Login
Access the dashboard
Add student data → appears as dynamic cards on the home page
Data persists using Local Storage
